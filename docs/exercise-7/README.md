# משימה 7 — זיכרון אוטומטי

## מה נשמר

נשמרה העדפה להדרכה בפעולה אחת עם תוצאה שאפשר לבדוק, והמתנה לתשובת המשתמש לפני ההמשך. שאלות מקבלות הסבר בלי התקדמות; בקשה מפורשת לתוכנית מלאה או לכמה צעדים גוברת על ברירת המחדל.

ההעדפה נכתבה בקובץ `guidance-one-step-at-a-time.md` בתיקיית זיכרון הפרויקט:

</div>

```text
~/.claude/projects/C--Users-wwwme-Desktop-file-browser/memory/
```

<div dir="rtl">

ב־`MEMORY.md` נוספה השורה:

</div>

```markdown
- [One guidance step at a time](guidance-one-step-at-a-time.md) — one checkable action per message, wait for reply; questions get explanations only
```

<div dir="rtl">

הקבצים נקראו ותוכנם אומת. הזיכרונות הקיימים נשארו ללא שינוי.

## איך נבדק

המשתמש אישר שיצא מהשיחה ופתח שיחה חדשה באמצעות `claude`, ללא `resume` או `continue`. בשיחה החדשה שלח, בלי להזכיר את ההעדפה:

> אני רוצה לבדוק שהאפליקציה עובדת בדפדפן. תנחה אותי.

בתגובה, Claude נתן פעולה אחת — להריץ `npm run dev` — וביקש לדווח על התוצאה לפני המשך ההדרכה. לפי דיווח Claude מאותה שיחה, שורת ההעדפה ב־`MEMORY.md` הייתה בקונטקסט בתחילתה; קובץ הזיכרון המפורט לא נקרא לפני התשובה.

**תוצאה:** הבדיקה הדגימה התנהגות בהתאם להעדפה השמורה בשיחה חדשה, ללא תזכורת מצד המשתמש.
